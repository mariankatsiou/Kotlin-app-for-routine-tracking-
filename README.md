# Routine Tracker

An Android app for building a weekly routine, written in Kotlin. Users add their own activities/tasks for each day, and the app stores everything locally on the device.

## What this app does

- Lets the user build a weekly schedule by adding their own activities day by day.
- Stores the routine locally on the device, so it's available offline and persists between sessions.
- Navigates between screens using Fragments and the Android Navigation Component.

## Tech stack

Kotlin · Android Fragments · Navigation Component (Safe Args) · Jetpack Compose · Room (local storage) · Gradle Kotlin DSL
